2. Technical Challenges & Remediation
The Blocker: Encountered a system boot failure immediately after creating the Virtual Machine, resulting in the error: "The virtual machine failed to boot. That might be caused by a missing operating system or misconfigured boot order."

Root Cause: The Virtual Machine was launched without a valid boot medium mounted, as the VirtualBox storage drive configurations were left empty.

Resolution: Successfully resolved the issue by accessing the VM Storage settings, manually mounting the official Windows Server 2019 ISO file into the virtual IDE/SATA optical drive controller, and executing a Retry Boot command to kickstart the system installation process.
